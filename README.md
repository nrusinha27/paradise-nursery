# Paradise Nursery Shopping Application (`e-plantShopping`)

Welcome to **Paradise Nursery**! This is a modern, responsive React-based e-commerce application built for browsing and purchasing houseplants.

## Repository Information
- **Repository Name:** `e-plantShopping`

## Features
- **Landing Page:** Features the company name ("Paradise Nursery"), description, and an interactive "Get Started" button that transitions seamlessly into the product catalog.
- **Product Listing Page:** Displays various house plants categorized logically with thumbnails, descriptions, prices, and an "Add to Cart" button that disables once added.
- **Shopping Cart Page:** Powered by **Redux Toolkit**, allowing users to:
  - View all added items with their individual sub-totals.
  - Increment or decrement item quantities.
  - Remove items completely from the cart.
  - Dynamically calculate and display the total cart amount.
- **Navigation Bar:** Includes quick-access links to toggle between the plant catalog and shopping cart, complete with a real-time badge tracking total item quantities.

## Technologies Used
- React.js (Functional Components, Hooks)
- Redux Toolkit (State Management)
- CSS3 for styling and layout
